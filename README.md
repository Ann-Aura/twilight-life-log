# 暮光记录

一个单用户的 AI 生活日志 MVP：随手记录生活碎片，让 AI 整理成当天回忆，并用日历回看。

## 当前功能

- 当天碎片记录、删除与本地保存
- 按日期回看原始记录和 AI 整理结果
- 近期记录统计
- 网页内 AI 配置：API 地址、Key、模型与自定义整理要求
- 支持兼容 OpenAI Chat Completions 的接口；可尝试自动拉取模型
- 可按起止日期读取日记，让 AI 生成阶段回顾并继续追问
- 可按日期范围导出 TXT 或 HTML 日记，支持附上原始碎片
- 支持 Chrome / Edge 的浏览器原生语音转文字；不支持时仍可正常文字输入
- 数据管理支持完整 JSON 备份，以及 GitHub Gist 跨设备同步

## 使用方式

直接用浏览器打开 `index.html`。点击右上角齿轮，在「AI 配置」中填写 API 地址、API Key 和模型名称，保存后即可使用「让 AI 整理」。齿轮中的「数据管理」可导出日记，后续也会放入 GitHub 备份与同步功能。

在「AI 回顾」页选择开始和结束日期，点击「开始回顾」。AI 会读取这段时间的原始记录和当日整理结果，先给出阶段回顾；之后可在同一页面继续提问。为避免单次请求过长，记录特别多时请缩短日期范围。

在齿轮的「数据管理」中选择导出范围，即可导出 TXT 或 HTML 文件；默认只输出 AI 整理，勾选「附上原始碎片」可制作完整备份。

同一页的「本地备份」可导出或导入完整 JSON 文件。GitHub 同步使用你自己的私密 Gist：创建细粒度 Personal Access Token 时，授予账户权限 `Gists: write`，填入 Token 后首次点击「备份到 GitHub」会自动创建备份 Gist。Token、AI Key 都不会写进备份文件；导入时会合并日记记录。自动备份仅在网页打开期间运行。

若使用 Chrome 或 Edge，记录框旁会显示「语音输入」。首次使用时请允许浏览器访问麦克风；语音识别由浏览器提供，失败时可直接继续手动输入。

> 提醒：生活记录和 API Key 都只保存在当前浏览器的本地存储中，不写入项目文件，也不会上传到 GitHub 仓库。清除浏览器数据会一并清除它们。

未来若公开部署，会改为后端安全保存密钥的模式。
